# 章节与知识组织

## 标题职责

默认分章交付；用户要求单文件、合并版或其他布局时遵循其选择。分章版可以另设目录文件，默认对应原文章节并保留编号和顺序；英文标题译为中文。

先沿原材料识别章、节与知识点，再安排完整来源正文和补充讲解。书籍与 PDF 通常已经有知识点结构，照实恢复即可；PPT 的连续页面也可以共同承载一个知识点。页码与 block 是来源线索，分页、解析块边界和供料文件名不直接成为成品的阅读结构。

| 层级 | 职责 | 划分依据 |
|---|---|---|
| `#` 一级 | 界定一个完整学习章节 | 一个知识领域或相对独立的问题范围 |
| `##` 二级 | 组织相互关联的知识点 | 一个共同问题、机制、流程、方案演进或对比 |
| `###` 三级 | 讲清一个可独立理解的问题 | 一个概念、机制、步骤、方法或关键区别 |

合并文件仍以一级表示学习章节，可在文件开头用普通文字放书名与目录；不要为加入书名而机械把全书降到四级。已有明确排版要求时允许调整层级，但保留章节、主题、知识点三种职责。简单主题可以止于二级，不补造三级标题凑结构。

来源已有小节标题时，将其恢复为对应的 Markdown 标题；不能把整章所有小节标题都写成普通文字或加粗文字。来源标题不足时，依据实际内容补有意义的主题标题，帮助读者定位正在理解的问题，不按页数或块数补标题。

把解析块还原为原页的阅读单元：编号与目录项配对为列表，跨块句子合成段落，表头与数据恢复成表格。编号、词条或断行各占一个 block，不意味着它们各占一个成品段落；原页的关系优先于提取遍历顺序。目录可直接成为导航，不重复附上同一套散落词条。版面关系不明时回看原页，不能凭猜测配对。

章首完整保留来源导言，按需要另段补充与前文的联系和必要基础；不强制使用“本章导读”等固定标题。三级之下优先用段落、列表、表格与代码组织；原文有更深的编号层级时照实保留，不为限制在三级而删除或改组原文。

## 先确定知识关系

保留来源论证顺序，按补充需要选择解释关系：

- 依赖：基础概念先于依赖它的方法。
- 因果：现象或问题 → 原因与机制 → 应对方式。
- 流程：输入 → 转换或状态变化 → 输出与检查。
- 演进：基础方案 → 暴露的限制 → 改进与代价。
- 对比：共同目标 → 各方案差异 → 选择条件。

这些关系用于安排补充解释，不取代原文章节与论证顺序；不能按照 block 类型把图、代码、公式拆到孤立章节。多个连续页面可以组成一个知识点；一个密集页面也可能包含多个知识点。先确定当前问题怎样推进，再把图放在需要其数据、结构或状态的具体步骤中，讲解接住图里的信息继续推理；图片位置不由页号、供料范围或主题标题边界决定。不要先汇集来源图、再集中写讲解、最后附整页截图，也不要把图集从节末挪到节首。跨页的例子、推导或方法保持对象和问题连续，来源与教学补充仍能辨认。

例如，来源连续介绍父节点的信息熵、划分后的子集熵和信息增益，可在“信息增益怎样决定分裂属性”下完整承接这段来源，串起划分前、划分后和二者之差；新的独立问题再分节。这个例子说明知识关系，不要求各类主题套用相同标题或段落模板。

每个概念的 AI 补充保留一个主要讲解位置；原文重复出现的实质内容仍保留，包括再次使用的条件、公式与例子。重复页眉或作为页眉使用的同一主题名属于排版线索，不必每页重抄成正文。第一次介绍关键概念时补足原理；再次使用时链接到前文并解释变化。跨文件回指应能定位相应主题。术语表、对比表和知识导图在有助于导航时提供，不用重复抄写正文充当导图。

## 前置知识与阅读层次

同一主题持续采用评估后确定的讲解路径；跨越明显不同的主题时才分别判断。前置铺垫、过程解释和例子最终都要回到原文的核心关系与结论，不因后半章篇幅增加而缩成概述。档位不改变来源顺序与内容范围，也不在正文中设置等级栏目。

组织复杂主题时结合读者已明确的基础，找出理解当前内容必需的概念；未知基础采用必要兜底。前置解释就近出现在首次使用处，用当前材料说明作用和关系，不能只展开缩写或给译名。展开到足以继续阅读即可，避免反复岔出去补独立基础课程；前文讲过时准确回指，并解释本次新用法，不认定用户已掌握。

基础机制与可选进阶内容混在一章时，用章首短阅读建议或自然分节标明学习顺序。例如先理解数据位置、搬运和访问，再理解复用与高级缓存策略。阅读建议可以提示先后，但不重排伴读正文或缩减用户要求的覆盖范围；被后文依赖的基础不能标作可跳过。不要给所有章强加“基础篇／进阶篇”。

## 标题说内容，正文自然衔接

译文与新增解释相邻、独立呈现，讲解可组合段落、表格、分类列表、步骤或图示；用具体符号、原例或问题自然承接，不为每段添加“补充理解”标签。自编例子或额外假设在需要时简短说明来源属性，呈现形式不等于省略这种说明。OCR 处理过程保存在内部工作记录；成品仅在对应位置说明影响当前理解的具体疑点。

避免连续重复“概念介绍／原理分析／案例展示”。可以写“异步返回为什么不代表执行完成”“怎样判断一次优化是否有效”。问题式和陈述式标题都可用，不必把每个标题写成问句。

让同一案例贯穿相关主题，逐渐增加复杂度。定义不必套用所有解释形式；难点则应深入，不能为了统一篇幅压缩推导。章节末尾按实际需要采用关系图、对比、自测或过渡，不强制同时出现全部形式。

## 调整结构时保留来源

来源内容按原顺序完整保留，英文以完整译文呈现，中文保留原文；图表、公式、代码就近呈现。PPT 连续页面可以组织为同一主题，但不能因此删掉页面中的知识、例子和条件。跨来源整合须保留对应定位及差异。只有页眉页脚等排版噪声或用户明确排除的范围可以省略；补充讲解可以合并、回指，不能据此删除来源正文。

## 小节供料与交付文件

小节包按源块边界提供材料，章首内容不因缺少小节标题而丢失。写作时恢复被提取拆开的自然段、列表和跨页续段；内部核对稿关联对应来源标记，合法合并按交付指南记录，不为检查方便把一句话拆成数个阅读段落。阅读稿只保留恢复后的阅读单元与必要页码。深层小节可以合并为一个交付文件，但保持编号和顺序；跨页正文、脚注和公式续段随对应内容保留。页眉中的章节名不能决定正文归属。图、表、公式及整页截图就近呈现，不另设集中资源章节替代随文阅读。
